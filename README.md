# LM IPTV

Applicazione IPTV nativa per Android TV e Amazon Fire TV, ottimizzata per l'uso con telecomando.

## Installazione su Fire TV

1. Scarica `LM-IPTV.apk` dalla pagina Releases di GitHub.
2. Abilita l'installazione di applicazioni sconosciute per Downloader.
3. Apri il file APK e seleziona **Installa**.

## Funzioni principali

- Playlist M3U/M3U8 e Xtream Codes.
- Live TV, film, serie ed episodi.
- Guida TV EPG/XMLTV.
- Profili, avatar, preferiti e cronologia di visione.
- Ricerca indicizzata e categorie personalizzabili.
- Interfaccia e player ottimizzati per telecomando Fire TV.

LM IPTV non include playlist, canali o contenuti. L'utente deve utilizzare esclusivamente sorgenti per le quali possiede i diritti necessari.
